# Invoice Maker

A simple, modern invoice generator built by **AAH Enterprises**. Create professional invoices in seconds, save them, search them and download them as PDF.

## Features

- Add client name, date and any number of items
- Automatic total calculation
- Save invoices and reopen them later
- Search saved invoices by client, date or invoice number
- Download invoice as PDF (print to PDF)
- Loading logo animation and smooth effects
- Gradient design that works on phones and desktops

## Built with

- HTML5
- CSS3 (gradients, grid, animations, print styles)
- JavaScript (DOM, localStorage)

## How to use

1. Download or clone this repository.
2. Open `index.html` in any browser.
3. Fill in the invoice and click **Save invoice** or **Download PDF**.

For PDF: in the print window, choose **Save as PDF** as the printer.

## Note

Saved invoices are stored in your browser (localStorage), so they stay on the device and browser where they were created.
